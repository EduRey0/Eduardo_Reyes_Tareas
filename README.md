# CRUD de Tareas en Solana

## Descripción

Este proyecto es un CRUD de tareas desarrollado en Solana usando Rust y Anchor.

Permite crear, leer, actualizar y eliminar tareas almacenadas en la blockchain.

---

## Funcionalidades

* Crear tareas
* Listar tareas por usuario
* Actualizar tareas
* Eliminar tareas

---

## Tecnologías

* Rust
* Anchor
* Solana (devnet)

---

## Cómo usar

1. Abrir el proyecto en Solana Playground
2. Hacer Build
3. Hacer Deploy
4. Ejecutar Test

---

## Estructura

```id="g3pz67"
src/lib.rs        # Programa en Rust
tests/anchor.test.ts   # Tests
```

---

## Nota

Cada vez que se ejecuta el test se crean nuevas tareas, ya que los datos en Solana son persistentes.
